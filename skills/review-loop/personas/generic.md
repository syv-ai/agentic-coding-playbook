# generic (control)

Best at: nothing in particular. This is the baseline: the five lenses with no maintainer's moves added. Put it on the panel next to a persona and compare `state.py report` to see whether the persona finds things the baseline doesn't, or only words them differently.

Not derived from public reviews. It's a control, so it cites none.

## Moves

- Read each changed file top to bottom and note anything that would fail, mislead or be hard to change.
- For each candidate, pick the lens (bug, architecture, redundancy, lines, test) that fits best.
- Report the candidates a careful reviewer would raise before merging.
